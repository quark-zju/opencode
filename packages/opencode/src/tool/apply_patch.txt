Edit files with a patch enclosed by `*** Begin Patch` and `*** End Patch`.

A patch may contain multiple file operations, and each update may contain multiple hunks. Each operation starts with one of:
- `*** Add File: <path>` followed by content lines prefixed with `+`
- `*** Update File: <path>` followed by an optional `*** Move to: <path>` and one or more `@@` hunks
- `*** Delete File: <path>` with no following content

Start an update hunk with `@@`, or `@@ <context>` to use an exact line as a location anchor. Immediately prefix each removed, added, or unchanged line with `-`, `+`, or one space; everything after that marker is file content.
