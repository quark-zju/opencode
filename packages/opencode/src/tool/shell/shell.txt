Run commands in a persistent ${shell} shell on ${os}.

Use this for terminal operations such as builds, tests, package managers, and git. Prefer dedicated tools for reading, searching, and editing files.
Commands run in the current directory by default; set `workdir` instead of changing directories in the command. Use `${tmp}` for temporary files outside the workspace.
By default, commands will time out after ${defaultTimeoutMs}ms unless `timeout` is set.
Output beyond ${maxLines} lines or ${maxBytes} bytes is truncated and saved to a file. Use read or grep on that file instead of truncating output in the command.
